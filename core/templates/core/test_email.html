About Test Email

Sends a short test message through the same mail server the app uses for all its notifications. Use it to confirm the server can still send email, for example when a user reports not receiving a notification.

The email is sent immediately. If the mail server rejects it, the error reported by the server is shown here so you can pass it on to whoever manages the email account.

Tips

  • Check the spam or junk folder if the message does not arrive within a few minutes.
  • A success message here means the mail server accepted the message, not that it reached the inbox.
  • The login password is never shown on this page.
